# Raspberry Pi RC Car

A Raspberry Pi-powered remote-control car built with **Python and GPIO**, featuring wireless control and PWM-based motor and steering control. The project focused on building modular hardware-control functions and tuning GPIO signals to improve the car's responsiveness and reliability.

## Features

* Wireless RC car control
* PWM-based motor speed control
* Steering control through GPIO signals
* Modular Python functions for hardware control
* Tuned GPIO signal timing for improved responsiveness
* Direct interaction with Raspberry Pi hardware

## Technologies

* **Python**
* **Raspberry Pi**
* **GPIO**
* **PWM**

## Project

This project was developed to explore hardware programming with the Raspberry Pi, focusing on controlling physical components through GPIO and PWM signals. The software was organized into modular functions for motor speed, steering, and peripheral control while tuning signal timing to improve overall responsiveness.

## What I Learned

* Controlling hardware using Raspberry Pi GPIO
* Using PWM signals for motor and steering control
* Structuring hardware-control logic into reusable functions
* Working with wireless input and real-time hardware responses
* Debugging and tuning hardware/software interactions
